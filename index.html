GelaGO

Locomotion prediction in virtual reality from head pose and gaze signals

Zicheng Liu

Southeast University

Paper (PDF) Dataset Code

Overview

This project studies continuous locomotion prediction in virtual reality from low-dimensional head-mounted display signals. Each recording synchronizes head pose, binocular gaze direction, eye openness, and avatar position on the ground plane, which together describe where a user is looking, where the head is oriented, and where the avatar is heading.

The model encodes the synchronized streams jointly rather than treating them as independent channels, and forecasts future avatar displacement from the observed history. The released data covers three locomotion techniques across three virtual scenes, recorded from 15 participants under a common protocol.

Dataset at a glance

Three locomotion techniques, Swing, Teleport, and Touchpad, each recorded in the Maze, Park, and Complex scenes. Every recording is a single CSV file with one row per sampled frame.

Access

The data archive is distributed as an AES-256 encrypted 7z file and can be downloaded directly from this site.

The extraction password is not published on this page. It is provided in the supplementary material of the paper. Downloading the archive alone does not give access to its contents.

Source code is maintained in a separate repository. The repository is private while the paper is under review and will be made public upon publication. See the code page for the current status.
