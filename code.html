What the repository contains

  • Data loading and preprocessing for the released CSV recordings
  • Model definition and training objective
  • Training and evaluation scripts for the reported configurations
  • Configuration files matching each table and figure in the paper

Environment

python >= 3.9
torch >= 2.0
numpy, pandas, scikit-learn

Install the dependencies into a clean environment before running any script. 

git clone https://github.com/ZichengLiu-seu/GelaGO.git
cd GelaGO
pip install -r requirements.txt

Workflow

Three steps, in order.

# 1. point the loader at the extracted archive
export GELAGO_DATA=/path/to/OpenSourceDataset

# 2. train
python train.py --config configs/default.yaml

# 3. evaluate
python evaluate.py --config configs/default.yaml --checkpoint runs/best.pt

Script names above reflect the released layout. If your checkout differs, refer to the README inside the repository, which is kept in sync with the code.

Data

The recordings are distributed separately from the code as an encrypted archive. Extraction requires the password given in the supplementary material.
