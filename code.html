Environment

Python 3.10 or newer, with a CUDA-capable GPU for the Mamba kernels. The encoder depends on mamba-ssm, which compiles CUDA extensions at install time and needs a matching CUDA toolkit on the machine. 

pip install torch numpy pandas scikit-learn
pip install mamba-ssm

Training runs five-fold cross validation with two held-out test subjects. Each fold builds its own loaders, trains with early stopping, and reports on the held-out subjects.

Data preparation

The loader expects a directory named motion with one subfolder per participant, holding the CSV recordings for that participant. 

LocomotionDataset/
└── motion/
    ├── 1/
    │   ├── SwingMazeScenesmoothData.csv
    │   └── ...
    ├── 2/
    └── ...

Only files whose names end in ScenesmoothData.csv are read, so a smoothed counterpart is required next to every recording. Set data_dir in the config to the parent of motion before running.

Run

Four configs ship with the repository, one per locomotion technique plus a combined setting. Each points at a data_dir that must be adjusted to your local path. 

python main.py --config_path="configs/GelaGO/gelago-touch.json"
python main.py --config_path="configs/GelaGO/gelago-tele.json"
python main.py --config_path="configs/GelaGO/gelago-swing.json"
python main.py --config_path="configs/GelaGO/gelago-all.json"

The four commands are also collected in start.sh. Logs are written to results/<model>/<interaction>/output.log, and the cross-validation summary is printed at the end of each run.

Data

The recordings are distributed separately from the code as a compressed archive.
