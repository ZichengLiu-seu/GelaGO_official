Dataset

Synchronized VR Locomotion Recordings

Head pose, binocular gaze, and avatar trajectory under three locomotion techniques

Composition

15Participants
3 × 3Techniques × Scenes
130CSV recordings
397 MBUncompressed

Participants are identified by numeric folder only. No name, age, gender, or any other identifying attribute is included in the release.

Locomotion techniques

  • Swing — continuous arm-swing driven locomotion
  • Teleport — discrete point-and-teleport
  • Touchpad — continuous joystick locomotion

Virtual scenes

  • Maze — corridor layout with occluded sightlines
  • Park — open outdoor environment
  • Complex — mixed indoor and outdoor layout

Archive layout

Each participant folder holds one CSV per technique and scene combination. The file name encodes both, for example 1/SwingMazeSceneData.csv. 

OpenSourceDataset/
├── Readme.txt
├── 1/
│   ├── SwingMazeSceneData.csv
│   ├── SwingParkSceneData.csv
│   ├── SwingComplexSceneData.csv
│   ├── TeleportMazeSceneData.csv
│   └── ... (9 files per complete participant)
├── 2/
│   └── ...
└── 15/

Three participant folders contain fewer than nine recordings. The missing combinations are visible from the file names.

Feature schema

Every CSV has a header row and 21 columns. One row corresponds to one sampled frame.

ColumnTypeDescription
timefloatTimestamp in seconds
pos_x, pos_y, pos_zfloatHead position in world coordinates
rat_w, rat_x, rat_y, rat_zfloatHead orientation as a quaternion
left_eye_opennessfloatLeft eye openness
right_eye_opennessfloatRight eye openness
left_eye_dir_w, x, y, zfloatLeft gaze direction as a quaternion
right_eye_dir_w, x, y, zfloatRight gaze direction as a quaternion
vr_pos_x, vr_pos_zfloatAvatar position on the ground plane
is_walkingboolLocomotion state flag

Extract

Enter the password when prompted. Both commands produce the same directory tree.

# 7-Zip
7z x OpenSourceDataset.7z

# Python
pip install py7zr
python -c "import py7zr; py7zr.SevenZipFile('OpenSourceDataset.7z').extractall('.')"

The Python snippet prompts for the password interactively. On macOS without 7-Zip installed, Keka or The Unarchiver both open this archive.

Usage terms

The archive is provided to support review and reproduction of the results reported in the paper. Redistribution of the archive or its contents is not permitted. A formal license will be applied when the dataset is publicly released.

The recordings contain no personally identifying information. Participant identifiers are numeric and carry no link to the original consent records.
